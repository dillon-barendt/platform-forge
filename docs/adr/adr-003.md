# ADR-003: Use Cookiecutter for Templating

- **Status:** Accepted
- **Date:** 2024-01-01

## Context

We need to choose a library for generating new projects from templates. The templating system should be easy to use,
well-documented, and support modern Python features.

## Decision

We will use [Cookiecutter](https://cookiecutter.readthedocs.io/) for templating.

## Consequences

- The templates will be written in a simple, declarative language that is easy to learn and use.
- The templates will be able to generate projects with a wide variety of files and directories.
- The templates will be easy to test and maintain.
