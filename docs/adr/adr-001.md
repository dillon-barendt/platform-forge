# ADR-001: Use Typer for the CLI

- **Status:** Accepted
- **Date:** 2024-01-01

## Context

We need to choose a library for building the command-line interface (CLI) for Platform Forge. The CLI should be easy to
use, well-documented, and support modern Python features like type hints.

## Decision

We will use [Typer](https://typer.tiangolo.com/) for the CLI.

## Consequences

- The CLI will be built on top of [Click](https://click.palletsprojects.com/), which is a popular and well-supported
  library for building CLIs.
- The CLI will have automatic help generation, command-line completion, and type validation.
- The CLI will be easy to test and maintain.
