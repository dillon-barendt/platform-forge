# ADR-002: Use Pydantic for Configuration

- **Status:** Accepted
- **Date:** 2024-01-01

## Context

We need to choose a library for managing the configuration for Platform Forge. The configuration should be strongly
typed, easy to validate, and support modern Python features like data classes.

## Decision

We will use [Pydantic](https://docs.pydantic.dev/) for configuration.

## Consequences

- The configuration will be defined using Python data classes, which are easy to read and write.
- The configuration will be automatically validated, which will help to prevent errors.
- The configuration will be easy to serialize and deserialize, which will make it easy to work with in other parts of
  the application.
