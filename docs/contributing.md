# Contributing Guide

This document provides a guide for contributing to Platform Forge.

## How to Contribute

There are many ways to contribute to Platform Forge, including:

- **Reporting bugs:** If you find a bug, please open an issue on
  the [GitHub repository](https://github.com/dillon-barendt/platform-forge/issues).
- **Suggesting features:** If you have an idea for a new feature, please open an issue on
  the [GitHub repository](https://github.com/dillon-barendt/platform-forge/issues).
- **Writing code:** If you'd like to contribute code, please see the [Development Guide](development.md) for
  instructions on how to get started.
- **Writing documentation:** If you'd like to contribute to the documentation, please see
  the [Development Guide](development.md) for instructions on how to get started.

## Code of Conduct

All contributors are expected to follow
the [Code of Conduct](https://github.com/dillon-barendt/platform-forge/blob/main/CODE_OF_CONDUCT.md).
