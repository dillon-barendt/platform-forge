# ADR-004: Use Material for MkDocs for Documentation

- **Status:** Accepted
- **Date:** 2024-01-01

## Context

We need to choose a library for building the documentation for Platform Forge. The documentation should be easy to
write, well-designed, and support modern features like search and syntax highlighting.

## Decision

We will use [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) for documentation.

## Consequences

- The documentation will be written in Markdown, which is a simple and easy-to-learn markup language.
- The documentation will have a modern and responsive design that looks great on all devices.
- The documentation will have a wide variety of features, such as search, syntax highlighting, and social sharing.
